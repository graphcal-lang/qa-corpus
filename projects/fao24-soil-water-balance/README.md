# FAO-24 soil-water balance

This source-backed reproduction asks: **Does an ordered monthly soil-water accumulation reproduce the March–August end balances printed in FAO Irrigation and Drainage Paper 24's cotton example?**

The project expands feature coverage with a record-shaped algebraic input type, constructor destructuring through `match`, a heterogeneous-accumulator `scan`, indexed tolerance assertions, `Bool` and `Int` results, `if`, `argmin` returning a typed key, key-based access, assumption metadata, and a line plot with a boolean color channel.

The source table, recurrence interpretation, and assertion mapping are documented in [`reference/calculation.md`](reference/calculation.md).
