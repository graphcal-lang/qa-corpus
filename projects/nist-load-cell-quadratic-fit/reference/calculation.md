## Sources and published expected values

National Institute of Standards and Technology:

- NIST/SEMATECH e-Handbook of Statistical Methods, “Load Cell Calibration — Background & Data,” https://www.itl.nist.gov/div898/handbook/pmd/section6/pmd611.htm;
- Statistical Reference Datasets, “Pontius,” https://www.itl.nist.gov/div898/strd/lls/data/Pontius.shtml; and
- Statistical Reference Datasets, “Pontius — Certified Values,” https://www.itl.nist.gov/div898/strd/lls/data/LINKS/v-Pontius.shtml;

accessed 2026-08-16.

The background and dataset pages publish all 40 `(deflection, load)` observations reproduced in the Graphcal multi-declaration. The Statistical Reference Dataset specifies the quadratic model

\[
D = \beta_0 + \beta_1 L + \beta_2 L^2 + \varepsilon
\]

and certifies:

- \(\hat\beta_0 = 0.673565789473684\times10^{-3}\);
- \(\hat\beta_1 = 0.732059160401003\times10^{-6}\) per source load unit;
- \(\hat\beta_2 = -0.316081871345029\times10^{-14}\) per squared source load unit; and
- residual standard deviation \(0.205177424076185\times10^{-3}\) with 37 residual degrees of freedom.

Those NIST-certified values—not locally generated extra digits—are the reference expectations. The STRD certified-values page is the numerical oracle.

## Adaptation and source-to-assertion mapping

The source does not assign a physical unit to “load units” or deflection, so the model preserves both as explicitly named conventional dimensionless values rather than inventing units. For numerical conditioning, it forms the design matrix with

\[
z=(L-1{,}575{,}000)/1{,}500{,}000.
\]

After solving in the centered coordinate, it transforms the coefficients to \(x=L/1{,}000{,}000\). Under that reporting normalization, NIST's certified coefficients are:

- intercept: `0.000673565789473684`;
- coefficient of \(x\): `0.732059160401003`;
- coefficient of \(x^2\): `-0.00316081871345029`.

The model forms \(X^T X\), forms \(X^T y\), solves the normal equations, evaluates residuals, and computes \(\lVert r\rVert_2/\sqrt{37}\). The manifest compares the unrounded Graphcal results directly with the NIST-certified decimals (after only the exact powers-of-ten coefficient normalization described above):

- `/node/source_intercept/si_value` = `0.000673565789473684`;
- `/node/source_linear_coefficient_per_million/si_value` = `0.732059160401003`;
- `/node/source_quadratic_coefficient_per_million_squared/si_value` = `-0.00316081871345029`;
- `/node/residual_standard_deviation/si_value` = `0.000205177424076185`.

The expected values are transcribed from NIST rather than generated by a local calculation. Narrow tolerances cover floating-point error in the Graphcal least-squares evaluation; they do not replace or add digits to NIST's certified values.
