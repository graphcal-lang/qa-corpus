# EPA combined-heat-and-power savings example

This source-backed reproduction asks: **Do the U.S. EPA's published combined-heat-and-power fuel and carbon-dioxide savings equations reproduce the results in its CEESC worked example?**

The project uses the rounded annual fuel-use and CO₂ values printed in Appendix A of the EPA methodology and evaluates the report's total-savings equations. The manifest checks only values explicitly reported by EPA. Source locations, unit adaptations, and assertion mappings are documented in [`reference/calculation.md`](reference/calculation.md).
