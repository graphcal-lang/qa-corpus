# NWS wind-chill example

This source-backed reproduction asks: **Does the National Weather Service wind-chill equation reproduce the NWS example for 0 °F air and a 15 mph wind?**

The NWS publishes both the equation and the expected whole-degree result of −19 °F. The source-to-assertion mapping and Fahrenheit adaptation are documented in [`reference/calculation.md`](reference/calculation.md).
